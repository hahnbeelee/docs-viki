# Source: https://docs.developer.yelp.com/docs/partner-apiyelpcom-basic-http-authentication

Most APIs using the `https://partner-api.yelp.com` subdomain are using basic HTTP Authentication over SSL (excluding Respond to Reviews API).

Each API (such as Data Ingestion API, Ads API, etc.) requires a separate set of credentials (username/password). These credentials are provided separately through your companies business development/partnership team. They will be provided to you directly via your Yelp account team.
