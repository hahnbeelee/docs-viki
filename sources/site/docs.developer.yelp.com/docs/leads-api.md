# 

Overview

The Yelp Leads API provides a means for Yelp partners to get notified, read and respond to Leads generated by Yelp users, such as conversations.

Access to the Leads API is currently limited to Yelp [advertising](https://business.yelp.com/partners/) and [listing management](https://business.yelp.com/data/listings/) reseller partners. Participation in these partnerships is subject to a minimum spend requirement. If you're interested in becoming a reseller partner to access the Leads API, please inquire on those pages for more information. For those who are not reseller partners, we recommend utilizing our [Zapier](https://docs.developer.yelp.com/docs/leads-api-zapier-integration) integration—a no-code solution that connects Yelp to your existing software and typically takes less than an hour to set up.

The partners will need to setup authorization and webhooks before they can use the APIs. Each of these setups are explained in detail in the next sections. Please note the Leads API does not support "Message the business", if a Yelp profile page has that, they won't be eligible to use the Leads API.

Once the initial authentication and webhook setups are done, the partners will get notified about every new interaction for the businesses they have subscribed to (see [Business Subscriptions API](https://docs.developer.yelp.com/docs/business-subscriptions-api) with type `WEBHOOK`). They can use the Read APIs (Get Lead/ Get Interaction events) to get the full list of interaction events for a particular lead. The Write APIs enable the partners to mark a lead as read, reply to a lead, and mark a lead as replied outside of Yelp.

Webhooks

Webhooks are used to notify the partner about a new lead, or a new interaction in an existing lead, for a given business. Follow the guide below to learn more about the leads webhooks.

[![docs.developer.yelp.com](https://files.readme.io/92f5032-small-174882.png)docs.developer.yelp.com\\ \\ Leads Webhooks](https://docs.developer.yelp.com/docs/leads-webhooks)

## 

Rate Limiting

All the Leads API endpoints have a default rate limit of 5 requests per second per client per endpoint. The limits are configurable for clients, contact us to know more.

## 

API Endpoints

The Leads API exposes endpoints for different use cases. Follow the links below to know more about each endpoint.

- [Get Lead](https://docs.developer.yelp.com/reference/get-lead)
- [Get Lead Events](https://docs.developer.yelp.com/reference/get-lead-events)
