# Source: https://docs.developer.yelp.com/docs/basic-usage

This guide will walk you through integrating the Yelp Yelp AI API with some of today's most widely used server frameworks. You'll learn how to:

- Set up a basic development environment
- Authenticate your API requests
- Make your first Yelp AI API call in your framework of choice

By the end of this guide, you'll have a working setup in your chosen framework that enables you to seamlessly integrate the Yelp Yelp AI API into your applications.

## 

Prerequisites

Before you start, ensure you have the following:

1. A Yelp Places API account, and an API key for authentication. Refer to [Places Authentication](https://docs.developer.yelp.com/docs/fusion-authentication) for further details.
2. The latest version of your chosen framework installed (Node.js, Python, Swift, etc.).
3. Access to our Recipes below for in-depth guides and ready-to-use sample code.

Next Steps

Great job setting up the Yelp AI API in your chosen framework! Now that you have the basics working, here's how to take your integration further:

- **Deepen Your Understanding**: Revisit our [Getting Started Guide](https://docs.developer.yelp.com/docs/yelp-fusion-ai-api) to learn when and how to include a **chat\_id** in your requests.
- **Explore API capabilities**: Visit our [Current Capabilities & Limitations](https://docs.developer.yelp.com/docs/current-capabilities-limitations) page to see what the AI API can do, along with any constraints and boundaries to keep in mind.
