# 

Partner APIs

If you are a Yelp Partner you may have been granted access to specific Yelp APIs. These APIs require separate set up and credentials each. Partner APIs use different sets of authentication methods:

- [Basic HTTP Authentication](https://docs.developer.yelp.com/docs/partner-apiyelpcom-basic-http-authentication) (username/password): Most partner-api.yelp.com API use basic HTTP authentication.
- [Yelp Places App API Key](https://docs.developer.yelp.com/docs/fusion-authentication): New Partner APIs use the same Places App API Key authentication as for Yelp Places.
- [OAuth Authorization](https://docs.developer.yelp.com/docs/oauth-authorization) for action on behalf of a specific business owner

> ## 📘
> 
> Please do not make API calls for an API that you do not have rights to. Each API requires a separate set of credentials. If you make a call for an API that you do not have rights to, you will get an error. If you are unsure which API you have access to, please reach out to your company's business development/partnership team.
