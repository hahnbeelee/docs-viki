# 

Overview

The Phone Number Management API provides a means for Yelp partners to manage and view outbound numbers that can call consumers, and the inbound number which receives calls from consumers.

Note that this is a subset of the [Leads API](https://docs.developer.yelp.com/docs/leads-api) \- access to Leads API is a prerequisite to getting access to the Phone Number Management API.

##
