Today, May 16th 2023, we are changing the daily rate limits for both Fusion and GraphQL for new clients.

| API | Old Limit | New Limit |
| --- | --- | --- |
| Fusion | 5,000 | 500 |
| GraphQL | 250,000 | 25,000 |

If your client was created before May 16th 2023 the old limits still apply.

Learn more about Rate Limiting here:

- [Fusion Rate Limiting](https://docs.developer.yelp.com/docs/fusion-rate-limiting)
- [GraphQL Rate Limiting](https://docs.developer.yelp.com/docs/graphql-rate-limiting)
