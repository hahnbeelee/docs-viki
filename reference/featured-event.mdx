The Featured Event endpoint returns the one event that Yelp's community managers have highlighted for a specific location. Unlike Events Search — which returns a ranked list — this endpoint returns a single curated event, making it ideal for hero placements or "happening near you" spotlight sections in your app. You must supply either a `location` string or a coordinate pair to identify the target area.

## Endpoint

```
GET https://api.yelp.com/v3/events/featured
```

<Note>
  Authenticate all requests with your private API Key in the `Authorization` header: `Authorization: Bearer YOUR_API_KEY`.
</Note>

## Query Parameters

<ParamField query="location" type="string">
  A string describing the target area (e.g., `"Chicago, IL"`). Required if `latitude` and `longitude` are not provided.
</ParamField>

<ParamField query="latitude" type="number">
  Latitude of the target area. Required if `location` is not provided. Must be paired with `longitude`.
</ParamField>

<ParamField query="longitude" type="number">
  Longitude of the target area. Required if `location` is not provided. Must be paired with `latitude`.
</ParamField>

<ParamField query="locale" type="string">
  Locale code for the response language (e.g., `en_US`, `fr_FR`). Defaults to `en_US`.
</ParamField>

## Example Request

<CodeGroup>
```bash cURL
curl -X GET \
  "https://api.yelp.com/v3/events/featured?location=Chicago,IL" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

## Response Fields

The featured event endpoint returns a single event object with the same schema used by the [Events Search](/reference/events-search) and [Event Details](/reference/event-details) endpoints.

<ResponseField name="id" type="string">
  Unique Yelp event identifier.
</ResponseField>

<ResponseField name="name" type="string">
  Name of the featured event.
</ResponseField>

<ResponseField name="description" type="string">
  Full event description.
</ResponseField>

<ResponseField name="url" type="string">
  Canonical URL to the event's Yelp page.
</ResponseField>

<ResponseField name="time_start" type="string">
  Event start time in `YYYY-MM-DD HH:MM` format (local time).
</ResponseField>

<ResponseField name="time_end" type="string">
  Event end time. May be `null` if no end time is set.
</ResponseField>

<ResponseField name="is_free" type="boolean">
  Whether the event is free to attend.
</ResponseField>

<ResponseField name="is_canceled" type="boolean">
  Whether the event has been canceled.
</ResponseField>

<ResponseField name="is_official" type="boolean">
  Whether the event is officially sponsored by Yelp.
</ResponseField>

<ResponseField name="attending_count" type="integer">
  Number of Yelp users attending.
</ResponseField>

<ResponseField name="interested_count" type="integer">
  Number of Yelp users interested.
</ResponseField>

<ResponseField name="category" type="string">
  Event category alias.
</ResponseField>

<ResponseField name="business_id" type="string">
  Yelp business ID of the host venue, if associated.
</ResponseField>

<ResponseField name="image_url" type="string">
  Cover image URL for the event.
</ResponseField>

<ResponseField name="cost" type="number">
  Minimum ticket price. `null` for free events.
</ResponseField>

<ResponseField name="cost_max" type="number">
  Maximum ticket price. `null` if not applicable.
</ResponseField>

<ResponseField name="tickets_url" type="string">
  External ticketing URL. `null` for free or unticketed events.
</ResponseField>

<ResponseField name="location" type="object">
  Structured venue address with `address1`, `city`, `state`, `zip_code`, `country`, and `display_address`.
</ResponseField>

<Tip>
  The featured event is selected by Yelp's community managers, not algorithmically — it may not always be the most popular or nearest event. Consider combining this with Events Search results for a richer events experience.
</Tip>
