---

The Reviews endpoint returns a list of review excerpts for a specific Yelp business. Each review includes a short text snippet of approximately 160 characters, the star rating, a link to the full review on Yelp, and basic information about the reviewer. You can look up reviews by Yelp business ID or alias. Access requires an **Enhanced or Premium plan** — review excerpts are not available on the Base plan.

## Endpoint

```
GET https://api.yelp.com/v3/businesses/{id}/reviews
```

## Authentication

Include your API key as a Bearer token in the `Authorization` header of every request.

```
Authorization: Bearer YOUR_API_KEY
```

## Path Parameters

<ParamField path="id" type="string" required>
  The Yelp business ID or alias for the business whose reviews you want to retrieve. You can obtain this value from the [Business Search](/reference/business-search) or [Business Match](/reference/business-match) endpoints.
</ParamField>

## Query Parameters

<ParamField query="locale" type="string">
  Locale code to filter reviews by language, for example `"en_US"` or `"fr_FR"`. Defaults to `"en_US"`.
</ParamField>

<ParamField query="offset" type="integer">
  Offset into the result set for pagination. Defaults to `0`.
</ParamField>

<ParamField query="limit" type="integer">
  Number of review excerpts to return. Plan limits apply:
  - **Enhanced plan**: maximum of **3**
  - **Premium plan**: maximum of **7**

  Defaults to `20`; the effective cap depends on your plan tier.
</ParamField>

<ParamField query="sort_by" type="string">
  Sort order for the returned reviews. Currently the only accepted value is:
  - `yelp_sort` (default) — Yelp's relevance-based ranking, considering recency, user voting, and review quality
</ParamField>

<Note>
  Only review **excerpts** (~160 characters each) are available through the API — full review text is not accessible via the API. To read the complete review, direct users to the `url` field in each review object.

  **Plan limits:**
  - **Base**: No access to review excerpts
  - **Enhanced**: Up to **3** excerpts per request
  - **Premium**: Up to **7** excerpts per request
</Note>

## Example Request

<CodeGroup>

```bash cURL
curl --request GET \
  --url 'https://api.yelp.com/v3/businesses/north-india-restaurant-san-francisco/reviews?sort_by=yelp_sort&limit=3' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

business_id = "north-india-restaurant-san-francisco"
url = f"https://api.yelp.com/v3/businesses/{business_id}/reviews"
headers = {"Authorization": "Bearer YOUR_API_KEY"}
params = {"sort_by": "yelp_sort", "limit": 3}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript Node.js
const axios = require("axios");

const businessId = "north-india-restaurant-san-francisco";
const response = await axios.get(
  `https://api.yelp.com/v3/businesses/${businessId}/reviews`,
  {
    headers: { Authorization: "Bearer YOUR_API_KEY" },
    params: { sort_by: "yelp_sort", limit: 3 },
  }
);
console.log(response.data);
```

## Response Fields

<ResponseField name="total" type="integer">
  The total number of reviews the business has on Yelp. This is the business's full review count, not just the number returned in this response.
</ResponseField>

<ResponseField name="reviews" type="array">
  Array of review excerpt objects.

  <Expandable title="Review object fields">
    <ResponseField name="id" type="string">
      Unique identifier for this review.
    </ResponseField>
    <ResponseField name="text" type="string">
      A review excerpt of approximately 160 characters. This is not the full review text. Direct users to `url` to read the complete review.
    </ResponseField>
    <ResponseField name="rating" type="integer">
      Star rating given by the reviewer, from 1 to 5.
    </ResponseField>
    <ResponseField name="time_created" type="string">
      Timestamp when the review was created, in `"YYYY-MM-DD HH:MM:SS"` format.
    </ResponseField>
    <ResponseField name="url" type="string">
      Direct URL to the full review on Yelp.
    </ResponseField>
    <ResponseField name="user" type="object">
      Basic information about the reviewer.

      <Expandable title="User object fields">
        <ResponseField name="id" type="string">Yelp user ID.</ResponseField>
        <ResponseField name="name" type="string">Reviewer's display name.</ResponseField>
        <ResponseField name="image_url" type="string">URL of the reviewer's profile photo. May be empty if no photo is set.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Tip>
  Display review excerpts alongside a "Read more on Yelp" link to the `url` field to comply with Yelp's display guidelines and give users access to the full content.
</Tip>
