Once a reservation is confirmed, you can use this endpoint to cancel it on behalf of the user. You can also check the current status of any booking using the companion status endpoint. Keep in mind that the Reservations API does not support editing bookings — if a user needs to change their reservation details, you must cancel the existing booking and create a new one.

<Warning>
  **Partner API — Access disabled by default.** The Reservations API is available only to Yelp partners. Apply for access at [yelp.com/fusion/vip/apply](https://www.yelp.com/fusion/vip/apply). Authenticate with your Yelp Places API Key (`Authorization: Bearer YOUR_API_KEY`).
</Warning>

---

## POST /v3/reservations/{id}/cancel — Cancel Reservation

Cancel a confirmed reservation.

```
POST https://api.yelp.com/v3/reservations/{reservation_id}/cancel
```

### Path Parameters

<ParamField path="reservation_id" type="string" required>
  The Yelp reservation ID returned when the booking was created via `POST /v3/bookings/{business_id}/reservations`.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl -X POST \
  "https://api.yelp.com/v3/reservations/res_PqrStuVwx987654/cancel" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

### Example Response

```json
{
  "reservation_id": "res_PqrStuVwx987654",
  "status": "cancelled",
  "cancelled_at": "2024-08-14T16:30:00+00:00"
}
```

### Response Fields

<ResponseField name="reservation_id" type="string">
  The Yelp reservation ID that was cancelled.
</ResponseField>

<ResponseField name="status" type="string">
  Updated reservation status. Will be `cancelled` upon successful cancellation.
</ResponseField>

<ResponseField name="cancelled_at" type="string">
  ISO 8601 timestamp of when the cancellation was processed.
</ResponseField>

## GET /v3/reservations/{id}/status — Get Reservation Status

Retrieve the current status of an existing reservation.

```
GET https://api.yelp.com/v3/reservations/{reservation_id}/status
```

### Path Parameters

<ParamField path="reservation_id" type="string" required>
  The Yelp reservation ID to look up.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl -X GET \
  "https://api.yelp.com/v3/reservations/res_PqrStuVwx987654/status" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

### Example Response

```json
{
  "reservation_id": "res_PqrStuVwx987654",
  "status": "confirmed",
  "date": "2024-08-15",
  "time": "19:00",
  "covers": 2,
  "business_id": "north-india-restaurant-san-francisco",
  "created_at": "2024-08-10T14:22:00+00:00"
}
```

### Response Fields

<ResponseField name="reservation_id" type="string">
  Unique Yelp reservation identifier.
</ResponseField>

<ResponseField name="status" type="string">
  Current reservation status. Possible values include `confirmed`, `cancelled`, `completed`.
</ResponseField>

<ResponseField name="date" type="string">
  Reservation date in `YYYY-MM-DD` format.
</ResponseField>

<ResponseField name="time" type="string">
  Reservation time in `HH:MM` format.
</ResponseField>

<ResponseField name="covers" type="integer">
  Party size.
</ResponseField>

<ResponseField name="business_id" type="string">
  Yelp business ID of the restaurant.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp when the reservation was originally created.
</ResponseField>

<Note>
  You **cannot edit reservations via the API**. To change a booking, cancel the existing reservation and create a new one using the full Openings → Holds → Book flow.
</Note>
