The Yelp Places API lets you surface authentic user reviews directly in your application. You can fetch up to three review excerpts per business on the Enhanced plan, or up to seven excerpts on the Premium plan. Review excerpts are not available on the Base plan. Review highlights are also available on Premium to showcase the most useful feedback. All reviews include a star rating, a short excerpt, a link to the full review on Yelp, and a reviewer profile.

<Note>
  The API returns **excerpts only** — approximately 160 characters per review. Full review text is not available through the API. To read a complete review, direct users to the `url` field returned with each review object.
</Note>

---

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v3/businesses/{id}/reviews` | Returns up to 3 (or 7 on Premium) review excerpts for a business. |
| `GET` | `/v3/businesses/{id}/review_highlights` | Returns curated review highlights. **Premium plan only.** |

---

## GET /v3/businesses/{id}/reviews

Retrieve review excerpts for any business by its Yelp business ID or alias. The response includes the reviewer's name, profile photo URL, rating, excerpt text, and a deep link to the full review.

<Note>
  **Sort order is not configurable.** Yelp determines the order of returned reviews based on a combination of recency, user voting, and review quality.
</Note>

### Parameters

<ParamField path="id" type="string" required>
  The Yelp business ID or URL-friendly alias for the business (e.g., `north-india-restaurant-san-francisco`).
</ParamField>

<ParamField query="locale" type="string">
  The locale for the response. Defaults to `en_US`. Use a supported locale code (e.g., `fr_FR`, `de_DE`) to receive translated content where available. See the [supported locales list](https://docs.developer.yelp.com/docs/resources-supported-locales) for all valid values.
</ParamField>

### Example Request

```bash
curl -X GET \
  "https://api.yelp.com/v3/businesses/north-india-restaurant-san-francisco/reviews" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

With locale:

```bash
curl -X GET \
  "https://api.yelp.com/v3/businesses/north-india-restaurant-san-francisco/reviews?locale=en_US" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response Fields

<ResponseField name="reviews" type="array">
  Array of review objects returned for the business.

  <Expandable title="Review object fields">
    <ResponseField name="id" type="string">
      Unique identifier for the review.
    </ResponseField>
    <ResponseField name="text" type="string">
      Excerpt of the review text, approximately 160 characters. This is **not** the full review. Use `url` to link users to the complete review on Yelp.
    </ResponseField>
    <ResponseField name="rating" type="integer">
      The star rating given by the reviewer. Value is between `1` and `5`.
    </ResponseField>
    <ResponseField name="time_created" type="string">
      Timestamp indicating when the review was created, in `YYYY-MM-DD HH:MM:SS` format.
    </ResponseField>
    <ResponseField name="url" type="string">
      Direct URL to the full review on Yelp. Link your users here to read the complete text.
    </ResponseField>
    <ResponseField name="user" type="object">
      Profile information for the reviewer.

      <Expandable title="User object fields">
        <ResponseField name="name" type="string">
          Display name of the reviewer (e.g., `"Hoang V."`).
        </ResponseField>
        <ResponseField name="image_url" type="string">
          URL of the reviewer's Yelp profile photo. May be an empty string if no photo is set.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer">
  The total number of reviews returned in this response (not the total number of reviews for the business).
</ResponseField>

<ResponseField name="possible_languages" type="array">
  List of language codes found in the returned review excerpts (e.g., `["en"]`).
</ResponseField>

## GET /v3/businesses/{id}/review_highlights

<Warning>
  This endpoint requires the **Premium plan**. Calls made without a Premium API key will return an authorization error.
</Warning>

Review highlights surface the most useful and representative feedback for a business, curated from the full pool of Yelp reviews. They are ideal for showcasing what customers say most frequently about a location.

### Parameters

<ParamField path="id" type="string" required>
  The Yelp business ID or URL-friendly alias for the business.
</ParamField>

### Example Request

```bash
curl -X GET \
  "https://api.yelp.com/v3/businesses/north-india-restaurant-san-francisco/review_highlights" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
