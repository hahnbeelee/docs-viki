The Yelp Places API lets you localize search results and business data by passing a `locale` parameter in your requests. Each locale code follows the pattern `{language_code}_{country_code}`, where the language portion uses [ISO 639-1](https://en.wikipedia.org/wiki/ISO_639-1) alpha-2 codes (or [ISO 639-2](https://en.wikipedia.org/wiki/ISO_639-2) alpha-3 when a two-letter code is unavailable), and the country portion uses [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) codes. When no `locale` is specified, the API defaults to `en_US`.

## Using the Locale Parameter

Pass the `locale` query parameter to any search or business-details endpoint to receive localized content such as translated category names and region-appropriate formatting:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
  "https://api.yelp.com/v3/businesses/search?term=ramen&location=Tokyo&locale=ja_JP"
```

<Note>
  Not all business data is translated. The `locale` parameter primarily affects category labels, sorting defaults, and the language of any Yelp-generated text. Business owner-provided content (names, descriptions) will appear in the language the owner entered.
</Note>

## Notes on Specific Locales

<AccordionGroup>
  <Accordion title="Multi-locale countries">
    Several countries appear multiple times in the table because they have more than one official or widely-used language. For example, Switzerland is available as `de_CH` (German), `fr_CH` (French), `it_CH` (Italian), and `en_CH` (English). Belgium appears as `nl_BE` (Dutch), `fr_BE` (French), and `en_BE` (English). Use the locale that best matches your end users' language preference.
  </Accordion>

  <Accordion title="Filipino (fil_PH)">
    Filipino uses the ISO 639-2 alpha-3 code `fil` because there is no ISO 639-1 two-letter code for the language. This is the only locale in the supported list that uses a three-letter language code.
  </Accordion>

  <Accordion title="Default locale">
    If you omit the `locale` parameter entirely, the API falls back to `en_US`. Always specify a locale explicitly if your application targets non-US English-speaking or non-English-speaking audiences.
  </Accordion>
</AccordionGroup>

<Tip>
  If your target country or language is not in the list above, use the closest available locale or default to `en_US`. You can open a feature request on the [Yelp Fusion GitHub page](https://github.com/Yelp/yelp-fusion/issues) to ask for additional locale support.
</Tip>
